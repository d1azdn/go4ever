# 📖 go4ever <a name="about-project"></a>
**GO4EVER** is a website project developed using HTML, CSS, and JavaScript syntax to create a clean and functional interface. This project was undertaken as a requirement to fulfill the assignment criteria for Dicoding.com, an Indonesian platform dedicated to teaching and improving programming skills.

## ⚙️ Production (done)<a name="production"></a>
This project progressed over the **course of two weeks** before its public release, following several key stages: starts with watching tutorials on Dicoding, designing the layout in Figma, then applying the design using HTML, CSS, and JavaScript to build the final product.

### Tech Stack <a name="tech-stack"></a>
- Basic web develompent, such as HTML, CSS, Javascript.
